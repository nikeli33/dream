# dream

Поздравительная страница: парящий рояль в облаках, ночное небо, которое зажигается по клику,
и музыка — всё в одном файле.

- `index.html` — сама страница (фон встроен в base64, стили и WebGL-шейдеры внутри)
- `Dreamsfall.mp3` — трек, играет по кнопке в левом нижнем углу

Открывается локально двойным кликом по `index.html` или по ссылке GitHub Pages.
